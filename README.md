# bambu-printer: a Claude Code skill for Bambu Lab printers (LAN mode)

Lets [Claude Code](https://claude.com/claude-code) check on and look after a Bambu Lab printer over your
local network, with no Bambu cloud account needed:

- **Status:** progress, layer, time left, nozzle/bed temperatures, error codes
- **Camera:** grabs a frame so Claude can look at the print and tell you how it's going
- **Watch:** follows a print to the end and reports back
- **Guard:** a thermal watchdog that **stops** the print on overheating, plus camera checks
  every few minutes that **pause** the print if it's clearly failing (spaghetti, part knocked loose)
- **Control:** pause / resume / stop, list and upload files, start a `.gcode.3mf`

Just ask things like *"how's the print going?"*, *"send me a camera picture"* or
*"guard this print while I'm out"*.

Built and tested on a **Bambu Lab A1** in LAN-only mode (see [tests/RESULTS.md](tests/RESULTS.md)).
A1 mini and P1 use the same local protocols and should work, but haven't been tested. X1 uses a different
camera stream, so the camera command won't work there.

## Requirements

- Claude Code
- [`uv`](https://docs.astral.sh/uv/) (the script installs its one dependency, `paho-mqtt`, by itself)
- **LAN mode** on the printer (Settings -> WLAN on the A1), with the printer connected once in
  [OrcaSlicer](https://github.com/SoftFever/OrcaSlicer). The skill reads the LAN access code from
  Orca's config at runtime and never stores it. Without Orca, set the `BAMBU_CODE` env var instead.

## Install

```bash
git clone https://github.com/tyty-the-eyety/bambu-printer-skill ~/.claude/skills/bambu-printer
~/.claude/skills/bambu-printer/scripts/bambu.py setup 192.168.1.50   # your printer's IP
~/.claude/skills/bambu-printer/scripts/bambu.py status
```

`setup` reads the printer's serial number from its TLS certificate and saves the IP and serial in
`~/.config/bambu-printer/config.json`, outside the repo. You can use the `BAMBU_IP`, `BAMBU_SERIAL` and
`BAMBU_CODE` env vars instead.

The script also works on its own, without Claude: run `bambu.py help` for the commands.

## Safety

- Claude only pauses, stops or starts prints when you ask it to (for example "guard this print"), and only for that print.
- The camera check pauses and never stops a print, so you can always resume it.
- The thermal guard is an **extra** layer on top of the printer's own thermal-runaway protection, not a
  replacement. It only runs while a Claude Code session is open.
- Don't leave a printer running with nobody around just because a skill is watching it.

## Tests

`tests/` holds the plan used to check the safety features on a real printer. It includes harmless test jobs
generated by `python3 tests/make_tests.py`, plus the results. Run the plan only while you're at the printer.
